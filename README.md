# Qdesign.kz — 3D-конфигуратор мебели

Тестовое задание: адаптивный конфигуратор корпусной тумбы на **Vite + JavaScript + Three.js**. Без React, backend и базы данных.

## Запуск

```bash
npm install
npm run dev
```

Сборка для публикации:

```bash
npm run build
npm run preview
```

## Публикация на Vercel

1. Загрузите репозиторий на GitHub.
2. В Vercel: **Add New Project** → выберите репозиторий.
3. Framework Preset: **Vite** (или оставьте автоопределение).
4. Build Command: `npm run build`
5. Output Directory: `dist`

В проекте уже есть `vercel.json` с этими настройками.

## Возможности

- Три шаблона: открытая тумба, тумба с дверцей, тумба с двумя ящиками.
- Размеры в миллиметрах с валидацией; дверца и ящики масштабируются вместе с корпусом.
- Цвета: белый, серый, орех (процедурная текстура дерева).
- Сцена Three.js: камера, тени, пол, OrbitControls, сброс камеры.
- Размерные линии с подписями в мм.
- Адаптивная вёрстка для мобильных экранов.

## Структура

- `index.html` — разметка интерфейса.
- `src/style.css` — стили и адаптив.
- `src/main.js` — состояние конфигуратора и обработчики UI.
- `src/scene.js` — сцена, свет, камера, рендер, OrbitControls.
- `src/furniture.js` — сборка корпуса, фасадов и материалов.
- `src/dimensions.js` — размерные линии и подписи.
